This repository holds group work for BINF6250, Algorithmic Foundations in Bioinformatics (Fall 2026), by Dianah Kasemire and Trang Do. The project08 folder implements the Viterbi algorithm for hidden Markov models in Python: an HMM class that checks its inputs, works in log space to avoid underflow, and finds the single most likely sequence of hidden states for a sequence of observations. The folder contains a Jupyter notebook (project08.ipynb) with the code, a demonstration on the example data, and 21 passing tests, plus a README with the pseudocode, test purposes, results, reflection, and AI-use disclosure. Later HMM projects (Forward, Backward, and Baum-Welch) will build on the same class.
